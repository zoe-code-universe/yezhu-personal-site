# 野猪个人独立站

野猪是面向个人服务者的独立站生成平台。当前版本已经从静态展示升级为可运行的完整 MVP：

- 手机号注册站主账号
- 生成个人独立站 slug
- 保存站主资料、职业、地域、性别、联系方式、会员等级
- 上传头像、封面图、作品图片和视频
- 公开个人主页
- 客户预约服务
- 客户留言互动
- 站主设置已满日期并拦截预约
- 后端持久化 JSON 数据和上传文件

## 本地运行

```bash
npm install
npm start
```

打开：

```text
http://127.0.0.1:8787
```

健康检查：

```bash
curl http://127.0.0.1:8787/api/health
```

## 关键路径

1. 站主进入首页，选择地域、职业、网站风格和颜色。
2. 后台填写手机号并注册。
3. 上传头像、封面、作品图片或视频。
4. 设置已满日期。
5. 点击“生成公开主页链接”。
6. 客户访问公开链接，查看主页、联系方式、档期，提交预约或留言。

公开页 URL 形式：

```text
/index.html?view=public&site=<slug>#preview
```

## 数据说明

默认本地数据目录：

```text
data/db.json
uploads/
```

这些目录被 `.gitignore` 忽略，不会提交到 GitHub。

生产部署可用环境变量：

```text
DATA_DIR=/var/data/db
UPLOAD_DIR=/var/data/uploads
PORT=10000
HOST=0.0.0.0
```

## 部署

GitHub Pages 只能托管静态页面，不能保存上传、预约和账号数据。完整项目需要部署 Node 服务。

本仓库包含 `render.yaml`，可部署到 Render，并挂载持久磁盘保存数据和上传文件。

## 当前 MVP 边界

- 手机号注册是本地格式校验，还没有短信验证码。
- 数据库使用 JSON 文件，适合 MVP 和小规模内测；正式商业化建议迁移 PostgreSQL。
- 上传文件保存在本机或部署平台磁盘；大规模图片/视频建议迁移对象存储。
- 微信通知目前是记录和展示联系方式，还未接企业微信/公众号消息 API。
